- MIPS：每秒执行多少<font color="#c0504d">百万条指令</font>【Million instructions per second】
$$MIPS = \frac{指令条数}{执行时间 \times 10^6} = \frac{主频}{CPI \times 10^6}$$
- MFLOPS：每秒执行多少<font color="#c0504d">百万次</font>浮点运算
	- MFLOPS = 浮点操作数次数/(执行时间 * $10^6$)
- GFLOPS：每秒执行多少<font color="#c0504d">十亿次</font>浮点运算
	- GFLOPS = 浮点操作数次数/(执行时间 * )
- TFLOPS：每秒执行多少<font color="#c0504d">万亿次</font>浮点运算
	- TFLOPS = 浮点操作数次数/(执行时间 * )
