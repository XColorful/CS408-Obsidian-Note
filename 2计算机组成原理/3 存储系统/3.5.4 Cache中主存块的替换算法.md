> 可结合操作系统[[3.2.4 页面置换算法]]

| | |
|---|---|
|<font color="#8064a2">随机算法</font>|- 啥都不管只要你想映射的这块cache有内容了，就<font color="#c0504d">直接覆盖替换</font>它<br>- 即使原先在这块cache上的数据可能经常会用到，可能刚刚用完，也没关系，替换了就是了<br>- <font color="#c0504d">现实中不会以这种方式设计</font>|
|<font color="#8064a2">先进先出FIFO</font>|- 按调入cache的先后顺序来淘汰，<font color="#c0504d">先进的先替换</font><br>- 需要记录进入cache的先后次序<br>- 实现起来比较简单<br>- 缺点就是只考虑了时间层面的问题，会把一些经常使用的也当作最早进入cache的块给替换掉|
|<font color="#8064a2">近期最少使用LRU</font>|- 把<font color="#c0504d">最近比较少用的替换掉</font><br>- 需要记录进入cache的先后次序<br>- 也需要软件计数器来记录使用的频率<br>- 实现起来是比较复杂且开销大<br>- 根据程序访问局部性原理选择近期使用得最少的存储块作为替换的块|
|<font color="#8064a2">最不经常使用LFU</font>|- 只统计使用次数，<font color="#c0504d">用的最少的就替换掉谁</font><br>- 通常也是需要硬件设计计数器支持|
