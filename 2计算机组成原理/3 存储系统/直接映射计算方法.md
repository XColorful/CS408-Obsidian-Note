- 【<font color="#c0504d">主存地址长度</font>】主存中存储单元个数为 $2^{10}$，则主存地址长度就是10
- 【<font color="#c0504d">Cache地址长度</font>】Cache中存储单元个数为 $2^{10}$，则Cache地址长度就是10
- 【<font color="#c0504d">Cache行的总位数</font>】 = 标记位数t + 数据位 + 1位有效位 + 1位脏位（回写策略）

| | |
|---|---|
|<font color="#9bbb59">t</font>|- 别名：【主存区号】【Tag位】【主存字块标记】<br>- 通过主存区的标记位数就能知道这个cache是属于主存的第几区<br>- t = 主存地址长度 - Cache地址长度<br>- <font color="#c0504d">t = 主存大小/Cache大小</font>|
|<font color="#9bbb59">c</font>|- Cache块的地址位数<br>- 如有1k个Cache行，则Cache块的地址位数=c=10|
|<font color="#9bbb59">m</font>|- 主存块的地址位数<br>- 如有1k个主存块，则主存块的地址位数=m=10|
|<font color="#9bbb59">b</font>|- 块内地址位数<br>- 如块的大小为32B，按字节编制，块内地址位数=b=5|
|<font color="#9bbb59">有效位</font>|每个Cache行一般都有一个有效位，判断Cache是否命中【<font color="#c0504d">计算位数一定要加上</font>】<br><font color="#c0504d">有效位的作用是指出所在Cache行中的信息是否有效</font>|
|<font color="#9bbb59">脏位</font>|如果是回写策略，则需要1个脏位【<font color="#c0504d">题目有回写策略记得加上</font>】|
|<font color="#9bbb59">LRU位</font>|如果有用LRU替换算法，则增加一位LRU位|
|<font color="#9bbb59">其他</font>|- <font color="#c0504d">m = t + c</font><br>- <font color="#c0504d">m = 主存地址长度 - b</font><br>- 主存地址长度 = t + c + b|
