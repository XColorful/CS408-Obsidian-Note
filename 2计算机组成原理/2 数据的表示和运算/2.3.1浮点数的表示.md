### 浮点数是什么？

- 浮点数是指用<font color="#c0504d">符号</font>、<font color="#c0504d">尾数</font>、<font color="#c0504d">基数</font>和<font color="#c0504d">指数</font>来表示的小数
- 浮点数有两种【<font color="#c0504d">双精度浮点数double</font>, 64位】【<font color="#c0504d">单精度浮点数float</font>, 32位】

| | |
|---|---|
|![[浮点数符号、尾数、基数、指数.jpeg]]|<font color="#c0504d">基数</font><br>- 二进制基数为2<br>- 基数越大，表示范围越大，但是精度越低<br><br><font color="#c0504d">符号</font><br>- 指使用一个数据位来表示数值的符号，1为负，0为正<br><br><font color="#c0504d">尾数</font><br>- 尾数的位数反映<font color="#c0504d">浮点数的精度</font><br>- 使用正则表达式、将表现形式多样的浮点数统一为一种表达式<br>- 规则：基数为2时，将小数点前面的值固定为1；基数为4时，尾数的最高两位不全为0<br><br><font color="#c0504d">指数（阶码）部分</font><br>- 阶码的位数反映<font color="#c0504d">浮点数的表示范围</font>|

### 浮点数的表示范围

| | |
|---|---|
|![[浮点数的表示范围.jpg]]|- 【正上溢】：大于最大正数<br>- 【负上溢】：小于绝对值最大负数<br>- 【正下溢】：0到最小正数之间<br>- 【负下溢】：0到绝对值最小负数之间<br>- 通俗来说，上溢就是大于最大数，下溢就是小于最小数|

### 浮点数举例

<font color="#9bbb59">阶码，位数均用补码表示，求a,b的真值</font>

| | |
|---|---|
|a=001;1.1001;|001对应值为1，即阶码为1，尾数1.1001对应值$-\frac{7}{16}$<br>$a=2^1 \times \left( -\frac{7}{16} \right) = -\frac{7}{8}$|
|b=001;0.01001|001对应值为1，即阶码为1，尾数0.01001对应值$+\frac{9}{32}$<br>$b=2^1 \times \left( \frac{9}{32} \right) = \frac{9}{16}$|

### 浮点数的规格化

- 规格化：规定尾数的最高数位必须是一个<font color="#c0504d">有效值</font>(1)
- 采用规格化浮点数的目的是为了增加数据的表示精度

![[浮点数的规格化.png]]

| | | |
|---|---|---|
|左规|- 当浮点数运算的结果为非规格化时要进行规格化处理<br>- 将尾数<font color="#c0504d">算术左移</font>一位，阶码减1|$b = 2^1 \times (+0.01001)$<br>$=2^0 \times (+0.10010)$|
|右规|- 当浮点数运算的结果尾数出现溢出（双符号位为01或10时）<br>- 将尾数算术右移一位，阶码加1|<font color="#9bbb59">a=010; 00.1100, b=010; 00.1000, 求a+b</font><br>$a = 2^2 \times 00.1100$; $b = 2^2 \times 00.1000$<br>$a+b = 2^2 \times 00.1100 + 2^2 \times 00.1000$<br>$= 2^2 \times (00.1100 + 00.1000)$<br>$= 2^2 \times 01.0100$<br>$= 2^3 \times 00.1010$|

### IEEE 754浮点数的范围

> 【<span style="background:#ff4d4f">常考选择题</span>】

📢：<font color="#c0504d">IEEE 754中尾数用原码表示，阶码用移码表示</font>

![[IEEE 754浮点数的范围.jpeg]]

|【以正数为例】|<font color="#c0504d">最小值</font>|<font color="#c0504d">最大值</font>|
|---|---|---|
|<font color="#c0504d">单精度</font>|E=1，M=0<br>$1.0 \times 2^{1-1023} = 2^{-1022}$|E=254, M=.111$\dots$, $1.111\dots \times 2^{254-127} = 2^{127} \times \left( 2 - 2^{-23} \right)$|
|<font color="#c0504d">双精度</font>|E=1, M=0<br>$1.0 \times 2{1-1023} = 2^{-1022}$|E=2046, M=.111$\dots$, $1.111\dots \times 2^{2046-1023} = 2^{1023} \times \left( 2 - 2^{-52} \right)$|
|死记硬背|单精度阶码取值1~254，偏移值为<font color="#c0504d">127</font><br>最小值为$1 \times 2^{1-127}$<br>最大值为$\left( 2 - 2^{23} \right) \times 2^{254-127}$|双精度阶码取值1~2046，偏移值为1023|
|理解1|<font color="#9bbb59">规定除去E为全0和全1表示0和无穷大的情况，所以阶码范围为1~254</font>||
