1. 把遇到数据相关的指令及其后续指令都暂停一至几个时钟周期知道数据  
	相关问题消失后再继续执行，可分为<font color="#c0504d">硬件阻塞和软件插入“NOP”指令</font>两种方法
2. <font color="#c0504d">数据旁路技术</font>：直接将执行结果送到其他指令所需要的地方，使流水线不发生停顿，因此<font color="#c0504d">不会引起流水线阻塞</font>
3. 通过编译器对数据相关的指令<font color="#c0504d">编译优化</font>的方法，调整指令顺序来解决数据相关
4. 流水线按序流动，不会出现WAR，WAW；只可能出现RAW（没有等到上一条指令写就去读）

| | |
|---|---|
|<font color="#c0504d">写后读相关WAR</font>|- 当前指令将数据写入寄存器后<br>- 下一条指令才能从该寄存器读取数据|
|<font color="#c0504d">读后写相关RAW</font>|- 当前指令读出数据后<br>- 下一条指令才能写入寄存器|
|<font color="#c0504d">写后写相关WAW</font>|- 当前指令写入寄存器后<br>- 下一条指令才能写入寄存器|
