- 假设一条指令的执行有<font color="#c0504d">5条</font>流水段

| | |
|---|---|
|<font color="#c0504d">取指</font>（<font color="#c0504d">IF</font>）：从IR或者Cache中取指令<br><font color="#c0504d">译码/读寄存器</font>（<font color="#c0504d">ID</font>）：操作控制器对指令进行译码，同时从寄存器堆中取操作数<br><font color="#c0504d">执行/计算地址</font>（<font color="#c0504d">EX</font>）：执行运算操作或计算地址<br><font color="#c0504d">访存</font>（<font color="#c0504d">MEN</font>）：对存储器进行读写操作<br><font color="#c0504d">写回</font>（<font color="#c0504d">WB</font>）：将指令执行结果写回寄存器堆|![[5段指令流水线.jpg]]|

- 设用时最长的流水段用时X秒(如200ns)，总执行时间为y秒(如700ns)，系统由N条指令，度为1
- 则<font color="#c0504d">单处理机用时</font>为y × N，<font color="#c0504d">流水线处理机用</font>时为y+(N-1)×X
- <font color="#c0504d">不能缩短单条指令的执行时间</font>，但对于整个程序来说，执行效率得到大幅提升
