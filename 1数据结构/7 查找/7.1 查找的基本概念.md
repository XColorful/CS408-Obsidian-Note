| | |
|---|---|
|<font color="#c0504d">查找</font>|- 在数据集合中寻找满足某种条件的数据元素的过程|
|<font color="#c0504d">查找表</font>|- 用于查找的数据集合|
|<font color="#c0504d">关键字</font>|- 数据元素中唯一标识该元素的某个数据项的值|
|<font color="#c0504d">平均查找长度</font>|- 所有查找过程中进行关键字比较次数的平均值|

### 查找的分类

| | | |
|---|---|---|
|<font color="#c0504d">静态查找表</font>|- 只作查找操作的查找表|- 顺序查找<br>- 二分查找<br>- 插值查找<br>- 斐波那契查找<br>- 线性索引查找|
|<font color="#c0504d">动态查找表</font>|- 表结构本身是在查找过程中动态生成的<br>- 查找时插入数据元素<br>- 查找时删除数据元素|- 二叉排序树<br>- 平衡二叉树<br>- B树<br>- 散列表|
