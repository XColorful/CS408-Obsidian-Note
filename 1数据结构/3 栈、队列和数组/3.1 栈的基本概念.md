### 栈的运算/操作

| | | |
|---|---|---|
|<font color="#c0504d">InitStack</font>(&S)|初始化栈|- 初始化一个空栈S|
|<font color="#c0504d">StackEmpty</font>(S)|判断栈是否为空|- 空则返回True|
|<font color="#c0504d">Push</font>(&S,x)|进栈|- 若S未满，则将x加入使之成为新栈顶|
|<font color="#c0504d">Pop</font>(&S,&x)|出栈|- 若S非空，则弹出栈顶元素，并用x返回|
|<font color="#c0504d">GetTop</font>(S,&x)|读栈顶元素|- 若栈非空，则用x返回栈顶元素|
|<font color="#c0504d">DestroyStack</font>(&S)|销毁栈|- 销毁并释放栈S占用的存储空间|
