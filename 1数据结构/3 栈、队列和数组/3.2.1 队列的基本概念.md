### 逻辑结构知识点

| | |
|---|---|
|<font color="#c0504d">队列</font>|操作受限的线性表|
|<font color="#c0504d">队头</font>|允许删除的一端|
|<font color="#c0504d">队尾</font>|允许插入的一端|
|<font color="#c0504d">操作特性</font>|先进先出|

### 队列的运算/操作

| | | |
|---|---|---|
|<font color="#c0504d">InitQueue</font>(&Q)|初始化队列|- 构造一个空队列Q|
|<font color="#c0504d">QueueEmpty</font>(Q)|判队列为空|- 空则返回True|
|<font color="#c0504d">EnQueue</font>(&Q,x)|入队|- 若队列未满，将x加入，使之成为新的队尾|
|<font color="#c0504d">DeQueue</font>(&Q,&x)|出队|- 若队列非空，删除表头元素，并用x返回|
|<font color="#c0504d">GetHead</font>(Q,&x)|读队头元素|- 若队列非空，则将队头元素赋值给x|
