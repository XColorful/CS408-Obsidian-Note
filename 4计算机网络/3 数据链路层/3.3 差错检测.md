### 检测分类

- <font color="#c0504d">检错码</font>：只能检测错误，不能纠正错误
- <font color="#c0504d">纠错码</font>：可以纠正错误，但是开销大

### 检错编码分类

| | |
|---|---|
|<font color="#8064a2">奇偶校验码</font>|- 在待发送的数据后面添加1位校验码，使整个数据（包括校验位）中“1”的个数为奇数或者偶数<br><br>- 如果有奇数个位发生误码，可以检查出误码<br>- 如果有偶数个位发生误码，不能检查出误码（漏检）|
|<font color="#8064a2">循环冗余校验CRC</font>|- CRC有很好的检错能力（漏检率非常低），可以检测出所有的单比特错误<br>- 计算比较复杂，但非常易于用硬件实现，因此被广泛应用于数据链路层<br>- CRC具有纠错能力，但数据链路层只使用了他的检错功能，检测到帧出错直接丢弃|

### 纠错编码分类

| | |
|---|---|
|<font color="#8064a2">海明码</font>|- 在有效信息位中加入几个校验码组成海明码，把海明码的每个二进制位分配到几个奇偶校验组中，当某一位出错后，就会引起有关的几个校验位的值发生变化<br>- 该方法不但可以发现错位，还能指出错位的位置<br>- 海明码可以纠正一位差错<br>- 纠错d位，需要码距2d+1的编码<br>- 检错d位，需要码距d+1的编码|
