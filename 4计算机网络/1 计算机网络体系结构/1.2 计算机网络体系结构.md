### 计算机网络体系的形成

- 相互通信的两个计算机系统必须高度协调工作才行，而这种协调是相当复杂的
- 分层可以将庞大而复杂的问题转化为若干个较小的局部问题，而这些较小的局部问题就比较易于研究和处理
- 数据链路层和网络层是点对点通信【计算机节点和计算机节点进行通信】
- 传输层是端到端通信【进程与进程通过端口进行通信】

### 实体、协议、服务和服务访问点

![[实体、协议、服务和服务访问点.png]]

| | |
|---|---|
|<font color="#8064a2">实体</font>|- 表示任何可以发送或接受信息的硬件或软件进程。同一层的实体称为对等实体|
|<font color="#8064a2">协议</font>|- 简称协议，是为了进行网络中的数据交换而建立的规则、标准或约定<br>- 协议是“<font color="#c0504d">水平的</font>”，即协议是控制对等实体之间通信的规则<br><br>协议的三要素<br>- <font color="#4bacc6">语法</font>：规定传输数据的格式<br>- <font color="#4bacc6">语义</font>：规定所要完成的功能<br>- <font color="#4bacc6">同步/时序</font>：规定各种操作的顺序|
|<font color="#8064a2">接口</font>（<font color="#8064a2">访问服务点 SAP</font>）|- 同一个系统中相邻两层的实体进行交互（即交换信息）的地方<br>- 仅仅在相邻两层间有接口，且所提供服务的具体实现细节对上一层完全屏蔽|
|<font color="#8064a2">服务</font>|- <font color="#c0504d">下层为相邻上层</font>提供的功能调用。<br>- 服务是“垂直的”，即服务是由下层向上层通过层间接口提供的|
|<font color="#8064a2">数据组成</font>|- <font color="#c0504d">SDU服务数据单元</font>：为完成用户所要求的功能而应传送到的数据。<br>- <font color="#c0504d">PCI协议控制信息</font>：控制协议操作的信息。<br>- <font color="#c0504d">PDU协议数据单元</font>：对等层次之间传送的数据单位。<br>- 每一层的PDU会作为下一层的SDU，然后和PCI组成该层的PDU，再作为下下层的SDU...直到物理层|

### 分层的基本原则

- 各层之间<font color="#c0504d">相互独立</font>，每层只实现一种相对独立的功能
- 每层之间界面自然清晰，易于理解，<font color="#c0504d">相互交流尽可能少</font>
- <font color="#c0504d">结构上可分割开</font>。每层都采用最合适的技术来实现
- 保持<font color="#c0504d">下层对上层的独立性</font>，上层<font color="#c0504d">单向</font>使用下层提供的服务
- 能促进标准化工作

### 各层的功能

| | |
|---|---|
|<font color="#8064a2">差错控制</font>|使相应层次对等方的<font color="#c0504d">通信更加可靠</font>|
|<font color="#8064a2">流量控制</font>|发送端的发送速率必须使接收端<font color="#c0504d">来得及接收、不要太快</font>|
|<font color="#8064a2">拥塞控制</font>|拥塞状态=结点<font color="#c0504d">来不及接受分组而要丢弃大量分组</font>的情况，网络层要采取一定措施缓解这种阻塞|
|<font color="#8064a2">分段和重装</font>|发送端将要发送的数据块<font color="#c0504d">划分</font>为更小的单位，在接收端再进行<font color="#c0504d">还原</font>|
|<font color="#8064a2">复用和分用</font>|发送端几个高层会话<font color="#c0504d">复用</font>一条低层的连接，在接收端再进行<font color="#c0504d">分用</font>|
|<font color="#8064a2">连接建立和释放</font>|交换数据前先<font color="#c0504d">建立一条逻辑连接</font>，数据传送结束后<font color="#c0504d">释放连接</font>|
