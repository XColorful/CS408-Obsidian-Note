<span style="background:rgba(240, 107, 5, 0.2)">为什么要划分子网</span>？
- 两级IP地址分类的地址空间流动率有时很低，用子网划分的方法来改善这个问题

<span style="background:rgba(240, 107, 5, 0.2)">划分子网的好处</span>
- 增加子网的数量 → 减少广播域的大小 → 减少了主机的数量 → 提高了IP地址的利用率
- 不增加网络的数量

<span style="background:rgba(240, 107, 5, 0.2)">什么是子网划分</span>？
- 将主机地址分为两个部分【子网网络地址和子网主机地址】的过程
- 未做子网划分的 ip 地址：网络地址＋主机地址
- 做子网划分后的 ip 地址：网络地址＋（子网网络地址＋子网主机地址）
