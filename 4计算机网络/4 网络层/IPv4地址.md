<span style="background:rgba(240, 107, 5, 0.2)">ABC类地址主要由网络号和主机号组成</span>
- 网络号标志主机/路由器所连接到的网络
- 主机号标志主机/路由器

<span style="background:rgba(240, 107, 5, 0.2)">环回测试网络</span>
- `127.x.x.x`是环回自检地址，不指派
- 最小的环回地址：`127.0.0.1`
- 最大的环回地址：`127.255.255.254`

<span style="background:rgba(240, 107, 5, 0.2)">最大可用网络数</span>
- A类最大可用网络数 = $2^{网络号} - 2$
- BC类最大可用网络数 = $2^{网络号}$
- 网络号为0，不指派
- 网络号为127，不指派

<span style="background:rgba(240, 107, 5, 0.2)">最大可用主机数</span>
- 最大可用主机数 = $2^{主机号} - 2$
- 主机号<font color="#c0504d">全为 1</font> 的地址是广播地址【`255.255.255.255`只能作为目的地址使用】
- 主机号<font color="#c0504d">全为 0</font> 的地址是网络本身【<font color="#c0504d">`0.0.0.0`只能作为源地址使用</font>】

<span style="background:rgba(240, 107, 5, 0.2)">DE地址</span>
- D 类和 E 类地址没有主机号
- 不可用于主机 IP
- D 类常被用于多播
- E 类是预留的分类，暂时未使用

<span style="background:rgba(240, 107, 5, 0.2)">IP分类的优点</span>
- 简单明了、选路（基于网络地址）简单

<span style="background:rgba(240, 107, 5, 0.2)">IP分类的缺点</span>
- 同一网络下没有地址层次，缺少地址层次的灵活性
- C类地址254个太少了，B类地址65534个又太多了，不能很好的与显示网络匹配
- 上述两个缺点都可用【CIDR】解决

A类地址网络号为左起第一个字节，B类为2个字节，C类为3个字节

根据第一个十进制判断网络类别【<127为A类】【128～191为B类】【192～223为C类】
