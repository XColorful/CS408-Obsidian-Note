### 信道分类

| | |
|---|---|
|<font color="#8064a2">按传输信号</font>|- 模拟信道用于传输模拟信号<br>- 数字信道用于传输数字信号|
|<font color="#8064a2">按传输介质</font>|- 无线信道、有线信道|

### 信号分类

| | |
|---|---|
|<font color="#8064a2">基带信号</font>|- 将数字信号1和0直接用两种不同的电压表示，然后送到数字信道上传输【<font color="#c0504d">基带传输</font>】|
|<font color="#8064a2">宽带信号</font>|- 将基带信号进行调制后形成频分复用模拟信号，然后送到模拟信道上传输【<font color="#c0504d">宽带传输</font>】|

### 通信方式

- 按照通信双方的交互方式可分为：单工通信、半双工通信、全双工通信
- 单工通信需要一条信道，而半双工通信和全双工通信需要两条信道

| | |
|---|---|
|<font color="#8064a2">单工通信</font>|- 单向通信【<font color="#c0504d">广播</font>】|
|<font color="#8064a2">半双工通信</font>|- 双向交替通信【<font color="#c0504d">通讯机</font>】|
|<font color="#8064a2">全双工通信</font>|- 双向同时通信【<font color="#c0504d">手机</font>】|

### 数据传输方式

| | |
|---|---|
|<font color="#8064a2">串行传输</font>|- 1比特1比特地按照时间顺序传输<br>【<font color="#c0504d">速度慢，费用低，适合远距离</font>】<br>【<font color="#c0504d">适用于计算机网络之间的传输</font>】|
|<font color="#8064a2">并行传输</font>|- 若干比特通过多条通信信道同时传输<br>【<font color="#c0504d">速度快，费用高，适合近距离</font>】<br>【<font color="#c0504d">适用于计算机内部的传输</font>】|
