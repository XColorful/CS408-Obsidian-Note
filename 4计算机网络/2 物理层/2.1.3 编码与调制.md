### 信道上传送的信号可以分为基带信号和带通信号

| | |
|---|---|
|<font color="#8064a2">基带信号</font>|- 基带信号<br><br>- 来源于信源的信号。将数字信号1和0直接用两种不同的电压表示，再送到数字信道上传输（基带传输）。<br>- 计算机输出的代表各种文字或图像文件的数据信号都属于基带信号。<br>- 基带信号就是发出的直接表达了要传输的信息的信号。如说话的声波就是基带信号。<br><br>- 基信号往往包含较多带的低频成分，甚至有直流成分，而许多信道并不能传输这种低频分量或直流分量。为了解决这个问题，就必须对基带信号进行调制|
|<font color="#8064a2">带通信号</font>|- 经过载波调制后的信号（即仅在一段频率范围内能通过信道）|

### 调制方式：基带调制、带通调制

| | |
|---|---|
|<font color="#8064a2">基带调制</font>|- 仅仅对基带信号的波形进行变换，使它能够与信道特性相适应。<br>- 经过变换后的信号仍然是基带信号。<br>- 由于基带调制是把数字信号从一种形式转换为另一种形式的数字信号，所以这种过程又称为编码|
|<font color="#8064a2">带通调制</font>|- 使用载波进行调制，把基带信号的频率搬移到更高的频段，并转换为模拟信号，这样就可以更好地在模拟信道中传输。|
