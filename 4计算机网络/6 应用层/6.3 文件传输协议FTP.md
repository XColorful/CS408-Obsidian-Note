- FTP使用<font color="#c0504d">TCP可靠的传输服务</font>
- FTP必须在整个会话期间保留用户的状态信息
- 服务器必须追踪用户在远程目录树上的当前位置
- <span style="background:rgba(240, 107, 5, 0.2)">FTP特点</span>
	- 提供交互式访问
	- <font color="#c0504d">运行客户指明文件的类型与格式</font>，运行文件具有存取权限
	- 适合在异构网络中的任意计算机之间传送文件
- <span style="background:rgba(240, 107, 5, 0.2)">FTP功能</span>
	- 提供不同种类主机系统（软硬件都可）之间的文件传输能力
	- 以用户权限管理的方式提供用户对远程FTP服务器的文件管理能力
	- 以匿名FTP的方式提供公用文件共享的能力，使用anonymous作为用户名
- <span style="background:rgba(240, 107, 5, 0.2)">FTP组成</span>
	- 一个主进程，负责接收新的请求
	- 若干个从属进程，负责处理单个请求
- <span style="background:rgba(240, 107, 5, 0.2)">主进程步骤</span>
	- 服务端打开21端口，使客户进程能够连接上。
	- 等待客户进程发出连接请求。
	- 启动从属进程处理客户进程发来的请求。主进程与从属进程并发执行，从属进程对客户进程的请求处理完毕后即终止。
	- 回到等待状态，继续接受其他客户进程发来的请求。

### FTP工作时用到的TCP连接

- FTP使用两个独立的连接的好处
	- 使协议更加简单和容易实现
	- 在传输文件的时候可以利用控制连接对文件的传输进行控制（如用户可以在文件传输过程中发送“请求中止服务”）
