### 设备控制器主要功能

- 接受和识别CPU发来的命令
- 数据交换（设备和控制器的数据交换+控制器和主存数据交换）
- 标识和报告设备的状态，以供CPU处理
- 地址识别；数据缓冲；差错控制
- <font color="#c0504d">设备控制器不属于操作系统范畴，它是属于硬件</font>

### 设备控制器的组成

| | |
|---|---|
|1. <font color="#8064a2">设备控制器与CPU的接口</font>|- 用于实现CPU与控制器之间的通信<br>- CPU通过<font color="#c0504d">控制线发出命令</font><br>- 通过<font color="#c0504d">地址线指明要操作的设备</font><br>- 通过<font color="#c0504d">数据线来输入输出数据</font>|
|2. <font color="#8064a2">设备控制器与设备的接口</font>|- 用于实现控制器和设备之间的通信|
|3. <font color="#8064a2">I/O逻辑</font>|- I/O逻辑用于负责<font color="#c0504d">接收和识别CPU的各种命名</font>（如地址译码）<br>- 根据CPU的命令对相应的设备发送命令<br>- 用于实现设备控制功能|

### 设备控制器有三种寄存器
> <font color="#8064a2">设备控制器中可被CPU直接访问的寄存器，也叫I/O端口</font>

| | |
|---|---|
|<font color="#8064a2">数据寄存器</font>|CPU 向 I/O 设备写入需要传输的数据|
|<font color="#8064a2">命令/控制寄存器</font>|- 比如要打印的内容是「Hello」，CPU 就要先发送一个 H 字符给到对应的 I/O 设备<br>- CPU 发送一个命令，告诉 I/O 设备，要进行输入/输出操作，于是就会交给 I/O 设备去工作<br>- 任务完成后，会把状态寄存器里面的状态标记为完成|
|<font color="#8064a2">状态寄存器</font>|- 目的是告诉 CPU 现在已经在工作或工作已经完成<br>- 如果已经在工作状态，CPU 再发送数据或者命令过来，都是没有用的<br>- 直到前面的工作已经完成，状态寄存标记成已完成，CPU 才能发送下一个字符和命令|

### CPU与I/O端口的通信方式

| | |
|---|---|
|<font color="#8064a2">端口 I/O</font>（<font color="#8064a2">独立编制</font>）|- 每个控制寄存器被分配一个 I/O 端口<br>- 可以通过特殊的汇编指令操作这些寄存器<br>- 比如 in/out 类似的指令|
|<font color="#8064a2">内存映射 I/O</font>（<font color="#8064a2">统一编制</font>）|- 将所有控制寄存器映射到内存空间中<br>- 这样就可以像读写内存一样读写数据缓冲区|
