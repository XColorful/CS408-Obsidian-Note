### 格式化的过程

| | | |
|---|---|---|
|<font color="#8064a2">第一步</font>|<font color="#c0504d">低级/物理格式化</font>|- 在磁盘可以存储数据之前，将它分为扇区<br>- 以便磁盘控制器能够进行读写操作|
|<font color="#8064a2">第二步</font>|<font color="#c0504d">分区</font>|- 将磁盘分为由一个或多个柱面组成的分区(如C区，D区)<br>- 每个分区的起始扇区和大小都记在磁盘主引导记录的分区表中|
|<font color="#8064a2">第三步</font>|<font color="#c0504d">高级/逻辑格式化</font>|- 创建文件系统的根目录<br>- 对保存空闲磁盘块信息的数据结构进行初始化|

### 其他相关概念

| | |
|---|---|
|<font color="#8064a2">引导块</font>|- 计算机启动时需要运行一个初始化程序（自举程序），该程序存放在ROM中<br>- 启动/系统磁盘：磁盘具有启动分区的磁盘|
|<font color="#8064a2">坏块</font>|- 对坏块的处理实质上就是用某种机制使系统不去使用坏块|
