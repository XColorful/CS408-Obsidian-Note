- <font color="#c0504d">磁盘调度算法的目的</font>：为了提高磁盘的访问性能，一般是通过优化磁盘的访问请求顺序来做到的
- <font color="#c0504d">寻道的时间是磁盘访问最耗时的部分</font>，如果请求顺序优化的得当，可以节省一些不必要的寻道时间，从而提高磁盘的访问性能
- 绝大数OS为改善磁盘访问时间，以簇（一组块）为单位进行空间划分

### 一次磁盘读/写操作需要的时间
#⭐ 
> <span style="background:#ff4d4f">常考选择题计算和大题，2010年统考大题考过，配合磁盘调度算法一起考</span>

|   |   |
|---|---|
|<font color="#8064a2">寻找时间Ts</font>（<font color="#8064a2">寻道时间</font>）<br>【<font color="#c0504d">一般最长</font>】|- 在读/写数据前，需要将磁头移动到指定磁道所花费的时间<br><br>寻道时间分两步：<br>1. 启动磁头臂消耗的时间s<br>2. 移动磁头消耗的时间：假设磁头匀速移动，每跨越一个磁道消耗时间为m，共跨越n条磁道<br>$T_s = s + m \times n$|
|<font color="#8064a2">延迟时间TR</font>|- 通过旋转磁盘，使磁头定位到目标扇区所需要的时间<br>$T_R = \left( \frac{1}{2} \right) \times \left( \frac{1}{r} \right)$<br>- 1/r就是转一圈所需的时间。找到目标扇区平均需要转半圈，因此再乘以1/2|
|<font color="#8064a2">传输时间TR</font>|- 从磁盘读出或向磁盘中写入数据所经历的时间<br>- 假设磁盘<font color="#9bbb59">转速为r</font>，此次读/写的<font color="#9bbb59">字节数为b</font>，每个磁道上的<font color="#9bbb59">字节数为N</font><br>$T_R = \left( \frac{b}{N} \right) \times \left( \frac{1}{r} \right)$<br>- 每个磁道可存N字节数据，因此b字节数据需要b/N个磁道才能存储。而读/写一个磁道所需的时间刚好是转一圈的时间1/r。|
|<font color="#8064a2">总的平均时间</font>|$T_a = T_s + \frac{1}{2r} + \frac{b}{rN}$<br>- 无法通过操作系统优化延迟时间和传输时间。所以只能优化寻找时间。|
