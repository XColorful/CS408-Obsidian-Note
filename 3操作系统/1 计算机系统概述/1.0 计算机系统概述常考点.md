### 1. 微内核

| | |
|---|---|
|<font color="#c0504d">微内核定义</font>|- 只把核心功能放入内核，其余功能用用户进程的形式运行在用户态|
|<font color="#c0504d">微内核优点</font>|- 内核足够小<br>- 基于C/S模式<br>- 应用机制与策略分离原理<br>- 采用面向对象技术|
|<font color="#c0504d">微内核缺点</font>|- 执行效率不高<br>- 开销较大|

### 3. 常考的三种操作系统对比

| | |
|---|---|
|<font color="#8064a2">批操作系统</font>|<font color="#c0504d">脱机使用计算机</font>；作业是批处理的；系统内多道程序并发执行；交互能力差；|
|<font color="#8064a2">分时操作系统</font>|多个用户同时使用计算机；<font color="#c0504d">人机交互强</font>；具有每个用户独立使用计算机的独占性；系统响应及时|
|<font color="#8064a2">实时操作系统</font>|能对控制对象做出及时反应；<font color="#c0504d">可靠性高</font>；<font color="#c0504d">响应及时</font>；但资源利用率低|

### 4. 常见的特权指令和非特权指令

| | | |
|---|---|---|
|<font color="#9bbb59">特权指令</font>|指不允许用户直接使用的指令|- 对I/O设备操作指令<br>- 存取特殊寄存器的指令<br>- 有关访问程序状态的指令<br>- 置中断指令; 关中断指令<br>- 清内存指令; 置时钟指令|
|<font color="#9bbb59">非特权指令</font>|允许用户直接使用的指令  <br>不能直接访问系统中的软硬件资源  <br>只限于访问用户的地址空间|- 访管/trap指令|

### 5. 常见的在管态和在目态运行的程序

| | |
|---|---|
|<font color="#9bbb59">核心态</font>【<font color="#9bbb59">管态</font>】|<font color="#c0504d">在核心态运行的指令和程序</font>：<br>- 时钟管理相关的指令【置时钟指令】<br>- 中断机制相关的指令【时钟中断程序】<br>- 原语相关的指令<br>- 系统控制的数据结构与处理【进程调度程序】【进程切换】【缺页处理程序】【系统调用命令】|
|<font color="#9bbb59">用户态</font>【<font color="#9bbb59">目态</font>】|<font color="#c0504d">在用户态运行的指令和程序/发生的事件</font>：<br>- 命令解释程序【属于命令接口，面向用户】<br>- 访管/Trap指令，跳转指令，压栈指令<br>- 广义指令（系统调用）的调用（<font color="#9bbb59">系统调用的调用发生在目态，系统调用程序发生在管态</font>）<br>- 外部中断，缺页（<font color="#9bbb59">缺页现象发生在目态，缺页处理程序发生在管态</font>）|
