- 最前面的第一个块是<font color="#4f81bd">引导块</font>，在系统启动时用于启用引导
- 接着后面就是一个一个连续的块组了，块组的内容如下👇

| | |
|---|---|
|<font color="#c0504d">超级块</font>|- 包含的是文件系统的重要信息<br>- 比如 inode 总个数、块总个数、每个块组的 inode 个数、每个块组的块个数|
|<font color="#c0504d">块组描述符</font>|- 包含文件系统中各个块组的状态<br>- 比如块组中空闲块和 inode 的数目等，每个块组都包含了文件系统中「所有块组的组描述符信息」|
|<font color="#c0504d">数据位图</font><br><font color="#c0504d">inode 位图</font>|- 用于表示对应的数据块或 inode 是空闲的，还是被使用中|
|<font color="#c0504d">inode 列表</font>|- 包含了块组中所有的 inode，inode 用于保存文件系统中与各个文件和目录相关的所有元数据|
|<font color="#c0504d">数据块</font>|- 包含文件的有用数据|
