### 基本概念

1. 调度是处理机进行分配，即<font color="#9bbb59">从</font><font color="#c0504d">就绪队列</font><font color="#9bbb59">中按一定算法（公平，高效的原则）选择一个进程并将处理机分配给他运行</font>，以实现进程并发地执行
2. 调度是多道程序OS的基础；调度是OS设计的核心问题

### 调度的层次分类

| | |
|---|---|
|<font color="#8064a2">层次分类模型图</font>|![[调度层次分类模型图.jpg]]|
|1. <font color="#8064a2">高级调度/作业调度</font>|- 是<font color="#4f81bd">内存与辅存</font>的调度，从后备队列中调度作业<br>- 每个作业只调入调出一次<br>- 通常存在于多道批处理系统中<br>- 内存与磁盘之间交换数据的状态转换：就绪态到挂起态（408不考挂起）|
|2. <font color="#8064a2">中级调度/内存调度</font>|- <font color="#4f81bd">目的是提高内存利用率和系统吞吐量</font><br>- 将暂时不能运行的进程调到外存等待，设为挂起态，最后修改状态为就绪态，挂在就绪队列上<br>- 是存储器管理中的对换功能|
|3. <font color="#8064a2">低级调度/进程调度</font>|- <font color="#4f81bd">从就绪队列中选取一个进程</font>，调用频率很高<br>- 各种OS都必须配置这种调度|
|<font color="#8064a2">三种调度的联系</font>|1. 作业调度为进程活动做准备，进程调度使进程正常活动<br>2. 中级调度将暂时不能运行的进程挂起，中级调度处于另外两个调度之间<br>3. <font color="#4f81bd">调用频率</font>：作业调度 < 内存调度 < 进程调度<br>4. 进程调度是最基本的，不可或缺|
