#### 从题目得到的同步互斥关系

| | |
|---|---|
|<font color="#9bbb59">缓冲区</font>|生产者、消费者共享一个初始为空、大小为 n 的缓冲区|
|<font color="#9bbb59">同步关系 1</font>|只有缓冲区没满时（优先级高），生产者才能把产品放入缓冲区（优先级低），否则必须等待|
|<font color="#9bbb59">同步关系 2</font>|只有缓冲区不空时（优先级高），消费者才能从中取出产品（优先级低），否则必须等待|
|<font color="#9bbb59">互斥关系</font>|缓冲区是临界资源，各进程必须互斥地访问|

#### 设置的信号量

| | |
|---|---|
|<font color="#9bbb59">empty</font>|- 同步信号量（对应同步关系 1）<br>- 表示生产者还能生产多少，即还能放入缓冲区多少产品<br>- 该数量小于等于 0，则生产者不能进行生产<br>- 初始化为 n|
|<font color="#9bbb59">full</font>|- 同步信号量（对应同步关系 2）<br>- 表示消费者还能从缓冲区取出多少，即当前缓冲区已有产品的数量<br>- 该数量小于等于 0，则消费者不能进行读取<br>- 初始化为 0|
|<font color="#9bbb59">mutex</font>|- 互斥信号量<br>- 实现对缓冲区的互斥访问<br>- 初始化为 1|
