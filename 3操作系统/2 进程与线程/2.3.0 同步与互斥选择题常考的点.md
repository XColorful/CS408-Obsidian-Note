1. <font color="#9bbb59">可重入代码/纯代码</font>：一种允许多个进程同时访问的代码；如进程映像中的共享程序段
2. PV操作实现的<font color="#9bbb59">同步的S的初值由用户确定</font>；如果期望的信息还没发送，则对应的初值为0，若信息已存在，则初值为非0的正数
	- PV操作实现的<font color="#9bbb59">互斥的S的初值=1</font>
3. 执行P操作的进程处于运行态；若P操作之后，S<0，则表示没有可用资源，该进程进入阻塞状态
4. 判断代码中的语句是否要互斥执行，可以从以下几个方面考虑【见王道书P121第43题】
	- 不同范围的变量不需要互斥（如进程A和进程B都有变量x，这是两个不同范围的变量，不用互斥）
	- 对变量赋值前，都有声明语句的话，不需要互斥（如<font color="#9bbb59">「int a; a=1; int a; a=2」</font>,a=1和a=2不需要互斥）
5. 信箱通信是一种间接通信
