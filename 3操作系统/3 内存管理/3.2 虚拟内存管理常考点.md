|<font color="#8064a2">虚拟存储概念相关</font>|- 虚拟存储器的<font color="#9bbb59">最大容量</font>是由计算机的地址结构决定的，与主存容量和外存容量没有关系<br>- 虚拟存储技术基于程序的<font color="#9bbb59">局部性原理</font>，局部性越好，虚拟存储系统越能更好地发挥作用<br>- 虚拟存储技术只能<font color="#9bbb59">基于非连续分配技术</font><br>- 使用<font color="#9bbb59">覆盖、交换</font>方法可以实现虚拟存储|
|<font color="#8064a2">页面置换算法相关</font>|- 无论采用什么页面置换算法，每种页面第一次访问时不可能在内存中，必然发生缺页，所以<font color="#9bbb59">缺页次数 ≥ 不同的页号数量</font>|
|<font color="#8064a2">缺页中断相关</font>|- 请求分页存储器中，<font color="#9bbb59">页面尺寸增大，存放程序需要的页帧数减少，缺页中断次数也会减少</font><br>- <font color="#9bbb59">影响缺页中断</font>的时间有：缺页率，磁盘读写时间，内存访问时间，执行缺页处理程序的CPU时间<br>- <font color="#9bbb59">缺页中断可能执行的操作</font>：置换页面，分配内存（不会进行越界出错处理)<br>- <font color="#9bbb59">缺页处理过程中可能执行的操作</font>：修改页表，分配页框，磁盘I/O（内存没有页面，需要从外存读入）|
|<font color="#8064a2">其他</font>|- 系统调用是由用户进程发起的，请求OS的服务<br>- 虚拟存储只能基于非连续分配技术<br>- 创建新进程可以通过系统调用完成<br>- <font color="#9bbb59">可以加快虚实地址转换的操作</font>：增大快表TLB的容量，让页表常驻内存<br>- 当磁盘利用率很高，但是CPU利用率不高时，<font color="#9bbb59">改进CPU利用率的操作</font>：增大内存的容量，减少多道程序的度数|
