|<font color="#c0504d">定义</font>|- 在页面置换时，出现频繁的页面调度行为<br>- 所有页面置换策略都有可能造成抖动|
|<font color="#c0504d">产生原因</font>|- 系统中同时运行的进程太多 → 分配给每个进程的物理块太少 → 进程在运行时频繁出现缺页 → 频繁的调动页面<br>- 主要原因是因为<font color="#9bbb59">页面置换算法不合理</font>|
|<font color="#c0504d">解决方法</font>|- 撤销部分进程<br>- 增加磁盘交换区大小和提高用户进程优先级都与抖动无关|
