### 逻辑地址与物理地址

| |<font color="#8064a2">逻辑地址</font>|<font color="#8064a2">物理地址</font>|
|---|---|---|
|<font color="#4f81bd">定义</font>|每个目标模块都从0号单元开始编址的地址|物理地址空间是指内存中物理单元的集合|
|<font color="#4f81bd">特点</font>|- 不同进程可以有相同的逻辑地址，这些逻辑地址可以映射到主存的不同位置<br>- 进程运行时，看到和使用的地址都是逻辑地址<br>- 将逻辑地址转换为物理地址的过程叫做<font color="#c0504d">地址重定位</font>|- 物理地址是地址转换的最终地址|

### 程序的链接与接入
> 将程序变成可在内存中执行的程序过程

| | |
|---|---|
|<font color="#8064a2">过程图</font>|![[程序的链接与接入.jpg]]|
|1. <font color="#c0504d">编译</font>|<font color="#4f81bd">编译</font>：由编译程序将用户源代码编译成若干目标模块|
|2. <font color="#c0504d">链接</font>|<font color="#4f81bd">链接</font>：由链接程序将目标模块和库函数链接，形成完整的装入模块<br><font color="#4f81bd">链接类别</font><br>- 静态链接<br>- 动态链接<br>- 运行时动态链接|
|3. <font color="#c0504d">装入</font>|<font color="#4f81bd">装入</font>：是由装入程序将装入模块装入内存运行<br><font color="#4f81bd">装入类别</font><br>- 静态装入：在编程时把物理地址计算好<br>- 可重定位装入：装入时把逻辑地址转换为物理地址，但装入后不能改变<br>- 动态重定位装入：执行时再决定装入的地址并装入，装入后有可能会换出|
|<font color="#8064a2">例图</font>|![[程序的链接与接入例图.jpg]]|

### 内存保护

| | |
|---|---|
|<font color="#8064a2">目的</font>|确保每个进程都有一个单独的内存空间|
|<font color="#8064a2">方法</font>|<font color="#4f81bd">方法1</font>：在CPU中设置一对上下限存储器，判断CPU访问的地址是否越界<br><font color="#4f81bd">方法2</font>：使用重定位寄存器和界地址寄存器（只有OS内存才可以使用这两个寄存器）<br>- 重定位寄存器/基地址寄存器含最小的物理地址值【<font color="#c0504d">用于“加”</font>】<br>- 界地址寄存器含逻辑机制的最大值【<font color="#c0504d">用于“比”</font>】<br>- <font color="#c0504d">逻辑地址 + 重定位寄存器的值 = 物理地址</font>|
