|---|---|
|<font color="#8064a2">驻留集</font>是什么|驻留集 = 给一个进程分配的物理页框（也叫做物理块）的集合|
|<font color="#8064a2">驻留集的大小</font>|1.分配给进程的页框越少，驻留在内存的进程就越多，CPU的利用率就越高<br>2.进程在主存中的页面过少，缺页率相对较高<br>3.分配的页框过多，对进程的缺页率没有大的影响|

|<font color="#8064a2">如何调入页面</font>|情况1：所访问的页面不在内存时 → 缺页中断 → 无空闲物理块 → 决定淘汰页 → 调出页面 → 调入所缺页面<br>情况2：所访问的页面不在内存时 → 缺页中断 → 有空闲物理块 → 调入所缺页面|
